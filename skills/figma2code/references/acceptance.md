# 验收清单

## 基准可信度

- [ ] 参考图与节点来自同一 frame/版本；截图尺寸、倍率、原点和浏览器环境已记录。
- [ ] 字体、图片及页面数据已加载；动态内容、动画和页面状态可重复。
- [ ] 缺失节点、多匹配 selector、不可见目标和推断值已列出。

## 视觉

- [ ] 关键元素 x/y/width/height 误差在项目阈值内；无约定时以 ≤ 2 CSS px 作为初始目标，按元素逐项报告。
- [ ] 字体、字重、字号、行高、字距、换行和文本内容一致；字体光栅化差异单列。
- [ ] 容器 padding、列宽、gap、基线与对齐关系一致。
- [ ] 图片资源、object-fit / object-position、比例、裁切与 SVG 颜色一致。
- [ ] 描边、圆角、背景、阴影和透明度已查看局部证据。
- [ ] 已覆盖设计提供的 viewport；额外响应式推断已说明。

## 行为与工程

- [ ] 页面无意外横向溢出；相关链接、按钮、表单及键盘焦点正常。
- [ ] hover/focus/展开等目标状态经过检查；没有设计的状态按项目规范实现并说明。
- [ ] 已运行项目相关 lint/typecheck/build 或明确记录无法运行原因。
- [ ] 没有整页截图替代 DOM、掩盖差异的 mask 或因精调引入无依据的绝对定位。

## 报告

记录运行 ID、设计版本、环境、每轮修改、截图路径、每元素实测差值、检查结果和未解决项。不要用单一百分比宣称“100% 复刻”。把无法访问素材、无法启动页面等阻碍与已经完成的代码工作区分。

达到关键项后停止额外迭代。超过预算仍不达标时交付证据和具体下一步，不把未验证状态写成通过。
